# Empty-path Equivalence and Frozen Slow Readability

> **For agentic workers:** Use superpowers:subagent-driven-development / executing-plans. User supplied the staged design; proceed with diagnostics and bounded probe training, without downloading or changing the planning architecture.

**Goal:** Separate metadata from implementation path, then test exported six-layer KV readability against final Slow Planning features under a frozen checkpoint.

**Architecture:** Scoped inference hooks preserve the production model. Preallocate and export all324 existing source observations into a frozen GPU memory cache (~33GB raw KV), then unload Fast/Slow and train only two small readouts. No pooling/truncation of the raw KV. Source/model/data identities and source feature versions are recorded and frozen. No data downloads.

- Source: expanded joint_final.pt step800, original pinned assets, TRAIN256/fourlogs, newVAL64/twologs, legacy4/onelog. Verify source SHA and data/feedback identities using existing checked_checkpoint. Legacy and newVAL separate; already observed diagnostic VAL, not new TEST.

Four forwards: none; fusion+external columns masked+metadata encoder output replaced by learned no_cache token; fusion+external masked+normal valid metadata; correct KV. enabled=True in both fusion masks, so all six fusion layers execute. First predeclared VAL row additionally compares full Context tensors; all rows retain exact saved none/masked/correct prediction guards (204 references). No model parameter updates.
- Step2 export: same single frozen Slow prefill per324 source observations, capturing post-language-model final eight hidden features (actual Slow head input), all6 pre-RoPE K/V, source3-axis positions/groups, original Slow prediction. Assert captured original head reproduces prediction exactly. No expert trajectory as input; saved causal Fast feedback stays unchanged. Raw K/V remain on GPU under64GiB working allocation cap; export numeric heads and summaries only. Source tensors/parameters remain immutable. Fail clearly on OOM/layout mismatch, no fallback/pooling/resolution changes.
- Two probes initialized seed42, no pretrained Head inherited: (1) full-KV attention reader, hidden128, eight time queries, six layers, K/V512-wide per-token concatenation of two heads, per-layer invertible TRAIN-RMS scaling, learned K/V projections, explicit3-axis sinusoidal position encoding, source token-type bias initialized to equal-logit prior mass per group, not forced posterior mass, concat6outputs+small FFN/pose head; (2) pointwise final-Planning-feature LayerNorm+MLP (same topology as original head), hidden256, same8x3 output. Positive control additionally uses the original frozen Slow Head with exact reproduction.
- Both probes use meanL1pose (m/rad), AdamW LR5e-4, WD.01, clip1,32-stepwarmup/cosine to10%,1024updates of batch8, deterministic TRAIN epoch shuffle (8192 samples=32epochs). Same target mini-batches and order; no Slow/Fast weights updated. Check TRAIN curves at256/512/1024 on same prior fixedTRAIN32 only; no VAL until both complete fixed budget. Save heads, optimizer/scheduler/RNG/target plan, final models and identity hashes. No assertion of convergence.
- Evaluate correct/fixed/shuffled inputs at same trained reader checkpoint. Reference = lexicographically first TRAIN source; shuffle = existing split/cohort-local derangement. Hold target positions/types when replacing compatible raw KV; report wrong/fixed as invalid offline interventions. Final-feature MLP uses identical correct/fixed/shuffled source selection. Saved frozen Fast512 feedback-producer predictions are an additional no-training baseline: readable KV may convey its input feedback, not necessarily new Slow scene reasoning. Optional no-input baseline is original matching-window CV and trajectory mean predicted from TRAIN GT only; these are reference diagnostics, never model input. Report same cohorts/speed/log strata and per-window error, correct-source advantage, original Fast/Slow metrics.
- Readability and useful planning are distinct: compare correct vs fixed/shuffled on both logs; separately compare absolute GT error to Fast and original Slow Head. One seed/2VAL logs cannot prove stable generalization. A failed KV probe cannot prove information absence, especially if final-feature probe also fails or TRAIN fit remains poor.
- Stage3 communication training is conditional on Step2 establishing convincing correct-source readability and useful held-log planning. Do not silently run full Fast training if Step2 is inconclusive. If justified, freeze Slow, retain common Fast states/params/data/metadata/budget, compare correct/fixed/shuffled conditions. This stage needs its own locked protocol and is not part of this probe budget.
